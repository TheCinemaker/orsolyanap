# Workspace AGENTS Rules & Brand Guidelines

## Brand Name Rule
- **Brand Name**: Always write **VISITKOSZEG** as a single word, uppercase (ALL CAPS), and without Hungarian accents (no Ö or Ő, no spaces, no hyphens).
- **Correct**: `VISITKOSZEG`
- **Incorrect**: `VisitKőszeg`, `VISIT KŐSZEG`, `visitkoszeg`, `Visit Kőszeg`
